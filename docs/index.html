Local PHP development.
Just files and folders.

Wharf runs PHP, nginx and Apache right on your computer — no Docker, no VM. Every folder is a project with a real address like my-kirby-site.localhost, HTTPS in one switch, and the PHP version it needs.

How it works

Three steps. No wizard.

  1. Pick a folder

    “Add project…” takes any folder right where it lives — your code never moves. Wharf proposes a name and the rules for your CMS; one click, and it runs.

  2. Start it from the tray

    Start, stop and open live in the tray menu. The window is there when you need it, not for a two-second action.

  3. Open a real URL

    Each project gets its own address, with HTTPS if you want it. Your computer finds it by itself: nothing to set up, no password, no port number in the address.

    https://my-kirby-site.localhost

Features

Everything a PHP project needs.
Nothing it doesn't.

  • Real addresses, no password

    Each project answers at <name>.localhost, which your computer knows by itself. No hosts file, no port numbers.

  • HTTPS with one switch

    Turn it on, and Wharf makes a certificate your browser trusts. Your computer asks once.

  • The PHP you need

    PHP already on your computer is used where it is. Any supported version is one click away, and each project can pick its own.

  • nginx or Apache

    Choose one for everything, or give a single project the other. Its address stays the same.

  • Knows your CMS

    Kirby, Laravel, WordPress, Statamic, Symfony, Craft CMS or Drupal: Wharf recognises the folder and picks the right webserver rules.

  • Your own settings

    One php.ini for every PHP version, and webserver rules per project — plain files, edited right in Wharf.

  • Logs per project

    Requests and errors, PHP's warnings included — one folder per project, one click away.

  • Lives in your tray

    Start, stop and open projects without a window. Quit Wharf, and everything it started stops.

  • Accessible

    Readable in light and dark, status shown by shape as well as colour, and the keyboard reaches everything.

FAQ

Questions, answered.

Does Wharf use Docker or a virtual machine?

No. PHP, nginx, Apache and mkcert run as ordinary programs on your computer. Nothing is put in a container and nothing is virtualised, so your files are as fast as your disk.

Will Wharf ask for my password?

Adding a project never does. The one prompt comes the first time you turn on HTTPS: your computer has to be told once to trust Wharf's certificates. Saying no is fine — HTTPS stays on, browsers show a warning until you trust it, and Settings offers to ask again.

Why .localhost and not .test?

The name .localhost is reserved for your own computer (RFC 6761). macOS, Linux and every current browser answer it by themselves, so nothing is written to the hosts file. A made-up ending such as .test needs the hosts file instead, which macOS 26 does not reliably read.

Which PHP versions can I use?

Any version already on your computer is used where it is. Every version that still gets security fixes can be downloaded from Settings. The default is the newest version in active support, and each project can pick its own.

Do I have to move my projects into a special folder?

No. Choose “Add project…” and pick the folder wherever it is — a Git checkout in your code folder is fine. It stays where it is, and removing the project never touches its files.

What is the www folder for?

It is optional: a place inside Wharf's own folder (~/Wharf/www) for anyone who likes all projects in one spot. A folder put there shows up in the app, ready to add with one click, and its name is the project's name. Most projects live somewhere else, and “Add project…” takes them from there.

Can I use Wharf without the app?

The app is what runs Wharf, but you never have to click through it: the whole setup is one JSON file that Wharf picks up again when you edit it by hand.

Is Wharf only for Kirby?

No — any folder of PHP is a project. When you add one, Wharf recognises Kirby, Laravel, WordPress, Statamic, Symfony, Craft CMS and Drupal and picks ready-made nginx and Apache rules for it. You can change the pick, or choose none, for each project.

What about MySQL, PostgreSQL, Node.js or Mailpit?

They are planned, but not built yet. The first version does PHP, and does it well.

Can I install an older nginx or Apache for one project?

Not yet. Wharf installs the newest nginx and Apache, because the places it gets them from rarely offer older versions. What works today: each project can use either nginx or Apache, and its address stays the same.

Is Wharf free?

Yes. Wharf is open source under the MIT licence: free to use, for personal and client work alike. The code is on GitHub.

Does Wharf collect any data?

No. There is no account, no analytics and no crash reporting. Wharf goes online only to download something you asked for. The privacy page lists every file it changes on your computer.

Can I download Wharf?

Not yet — there are no installers. The desktop app runs on macOS today when built from source with make gui; see the README.
